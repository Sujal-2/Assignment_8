# Trello Demonstration Checklist

Use `trello-import.csv` to create cards, then organise lists as Product Backlog, Sprint 1, To Do, In Progress, In Review, Testing, Done, and Future. Add story point, priority, owner, due date, acceptance checklist, and requirement link to each card.

Capture genuine screenshots of:

1. Whole board with lists and labels visible.
2. One expanded card showing story, points, owner, due date, checklist, and comments.
3. Activity log showing at least three meaningful moves or updates.
4. Sprint 1 filtered view or dashboard.

Recommended activity trail: create cards → prioritise backlog → move Sprint 1 work to To Do → assign roles/dates → move implementation to In Progress → attach test evidence → move accepted stories to Done. Do not fabricate screenshots; preserve the Trello timestamps and board URL as real evidence.
